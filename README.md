# Typing Practice

A long-term typing practice repository documenting my journey from learning touch typing from scratch to developing speed, accuracy, consistency, and professional typing habits.

## 🎯 Overview

This repository contains my daily typing practice, exercises, and progress as I work toward becoming a faster and more accurate typist.

I started learning typing from the fundamentals and gradually developed proper **10-finger touch typing** skills through consistent practice.

The goal is not only to increase typing speed, but to build accuracy, muscle memory, consistency, and efficient keyboard usage that can support my work as a software engineer.

## 🚀 My Typing Journey

I started practicing typing from the ground up and focused on developing proper touch-typing technique rather than relying on a small number of familiar fingers.

Over time, I practiced:

- Proper finger placement
- Home-row positioning
- 10-finger touch typing
- Alphabet typing
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols and special characters
- Shift-key combinations
- Punctuation
- Common words
- Sentences
- Paragraphs
- Mixed characters
- Numbers and symbols
- Programming-related characters
- Speed drills
- Accuracy drills
- Long-form typing
- Consistency and endurance
